# Настройка и развёртывание

## Секреты сервера

| Переменная | Назначение |
|---|---|
| `VIBE_API_KEY` | Ключ серверных вызовов VibeCode, в том числе AI Router. |
| `BPMN_OAUTH_KEY` | OAuth-ключ приложения для операций авторизованных сотрудников. |
| `VIBE_APP_KEY` | Поддерживаемое старое имя `BPMN_OAUTH_KEY`. |
| `VIBE_OWNER_IDS` | Список идентификаторов владельцев через запятую. Для новой среды задавайте его явно. |
| `BPMN_AI_DATA_DIR` | Постоянная папка планов и контрольных точек ИИ. По умолчанию `/data/bpmn-ai-plans-v2`. |
| `PORT` | Порт HTTP-сервера, по умолчанию `3000`. |

Ключи задаются в секретах сервера VibeCode либо в локальном `.env`, исключённом из Git. `.env.example` содержит только пустые значения и обозначения для заполнения.

## Профиль VibeCode

- Среда: `node24`.
- Команда: `node server.mjs`.
- Порт: `3000`.
- Постоянные данные: каталог, указанный в `BPMN_AI_DATA_DIR`.
- Доступ выбранных сотрудников и разрешения Диска/статей настраиваются в платформе.

При обновлении сохраняйте полный действующий набор переменных окружения, настройки доступа и постоянные данные. Этот экспорт не содержит настроек сервера и не запускает автоматическое развёртывание.

## Перенос

Текущий профиль привязан к существующему порталу и домену приложения. В `server.mjs` проверьте `origin`, проверку портала при верификации сессии, настройки владельца и шаблоны ссылок публикации. В `index.html` проверьте возврат в статью. Перенастройте OAuth и серверные ограничения на стороне новой платформы; затем проверьте вход владельца и сотрудника, запрет чужой сессии и Origin, доступ к Диску и публикацию.

`VIBE_OWNER_IDS` не заменяет OAuth-настройку сотрудников. Схемы публикаций и права на исходные файлы не переносятся одной загрузкой кода.

## Проверка после обновления

Откройте приложение из Битрикс24; проверьте создание и редактирование, импорт/экспорт, сохранение на Диск и открытие конкретной схемы из статьи. Для ИИ проверьте создание, правку комментарием и продолжение после прерывания. Не заменяйте действующую диаграмму частичным или не прошедшим проверки ответом Router.
