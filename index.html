Сохранение схемы

Изменения сохраняются в этом браузере. Используйте экспорт BPMN для резервной копии.

Создайте свой процесс

1. Выберите элемент слева, затем нажмите на холст.
2. Для соединения выделите элемент и выберите стрелку в контекстном меню.
3. Дважды щёлкните, чтобы изменить подпись, или используйте панель свойств.
4. User Task — работа пользователя, Service Task — автоматическая работа системы.
5. Экспортируйте схему в BPMN, SVG, PNG или PDF.

PNG и PDF содержат открытый уровень схемы на белом фоне. Свёрнутые подпроцессы открываются значком в правом нижнем углу; BPMN сохраняет все уровни. PDF — один лист A3 с автоматической ориентацией. Черновики хранятся только в текущем браузере.

Диск Битрикс24

Файлы Битрикс24 в пределах ваших прав доступа. Сохранение создаёт новый файл BPMN.

Можно открыть .bpmn, .drawio, .xml или .txt с XML схемы. Экспорт в PNG, PDF и SVG остаётся в меню «Экспорт».

Опубликовать в статью

Выберите статью Базы знаний 2.0. Будут добавлены изображение схемы, исходный BPMN XML в файле .txt и ссылка на редактор. Нужно право редактирования статьи.

Открыть схему из XML

Вставьте XML BPMN 2.0 или draw.io. Импорт заменит текущую схему. Сначала сохраните её, если она нужна.

Draw.io преобразуется в редактируемую BPMN-схему. Подписи, связи и расположение переносятся. Цвета и нестандартные фигуры упрощаются; пулы и группы становятся обычными блоками. Сохранение — в формате BPMN.
