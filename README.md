# BPMN Студия для Битрикс24

Исходники опубликованного приложения VibeCode, снимок **v35** от 5 ноября 2026 года. Это редактор BPMN 2.0 с генерацией редактируемых схем по описанию и последующими исправлениями в диалоге.

## Возможности

- BPMN 2.0: задачи разных типов, события, шлюзы, пулы и дорожки; цвет и оформление элементов.
- Изменение размеров и повороты, сохранение привязки стрелок; настройки подписей и отмена правок.
- Импорт BPMN/XML, вставка XML и открытие drawio; экспорт BPMN XML, SVG, PNG и PDF.
- Открытие и сохранение на Диск Битрикс24, публикация в выбранную статью базы знаний, открытие связанной схемы и обновление публикации.
- Генерация и проверка через AI Router VibeCode, модель `bitrix/bitrixgpt-6.0-agent`.
- Сохранение промежуточных этапов, локальное исправление узлов и стрелок, дробление проблемных проверок, ограниченные адаптивные повторы.
- Встроенное [руководство BPMN](docs/BPMN_GUIDE.md) и структурные проверки схем.

## Запуск

Нужен Node.js 24 или новее. Сервер использует встроенные модули Node.js; браузерные библиотеки поставляются готовыми файлами в этом снимке.

```sh
cp .env.example .env
npm test
npm start
```

Редактор доступен на `http://localhost:3000`. Интеграции с Битрикс24 требуют настроенной платформы, секретов и запуска через её авторизованную среду. Локальный запуск сам по себе не создаёт пользовательскую сессию Битрикс24.

Это снимок действующего приложения: адрес приложения, допустимый портал и часть настроек владельца заданы в `server.mjs`; возврат в статью использует адрес портала в `index.html`. Перед переносом на другой портал или домен эти места необходимо адаптировать вместе с настройками OAuth и проверкой Origin. В текущем приложении настройки доступа сотрудников остаются на стороне VibeCode/Битрикс24.

См. [настройку и развёртывание](docs/DEPLOYMENT.md), [архитектуру](docs/ARCHITECTURE.md) и [известные ограничения](docs/KNOWN_LIMITATIONS.md).

## Проверки

```sh
npm run check
npm test
```

В репозиторий добавлены автономные тесты транспорта ИИ, ограничений восстановления и детерминированной компиляции BPMN. Они используют искусственные ответы Router и не расходуют квоту ИИ. Полный прежний набор браузерных испытаний не входил в опубликованный снимок и не восстановлен в этом экспорте.
